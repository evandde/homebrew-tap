# Homebrew Tap

Personal Homebrew tap for evandde's projects.

## Installation

```bash
brew tap evandde/tap
brew install <formula>
```

## Available packages

- g4starter - Interactive CLI for generating Geant4 simulation projects
  - [Repository](https://github.com/evandde/G4Starter)
  - Install: `brew install g4starter`

## Updating

```bash
brew update
brew upgrade <formula>
```
